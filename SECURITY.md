## Reporting a Vulnerability

We take the security of AccessHub seriously. If you believe you have found a security vulnerability, please follow the steps below:

### How to Report
Please **DO NOT** report security vulnerabilities through public GitHub issues.

Instead, please report vulnerabilities by emailing us directly or using GitHub's Private Vulnerability Reporting feature.

- **Email:** sineth1211@gmail.com
- Please include as much detail as possible to help us understand and reproduce the issue (steps to reproduce, affected endpoints, potential impact, etc.).

### What to Expect
- **Response Time:** We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Fix Time:** We will work on a fix and keep you updated on our progress.
- **Disclosure:** Once the vulnerability is fixed, we will publish an update and give proper credit to the reporter (if desired).

Thank you for helping keep AccessHub safe for everyone!
